# CU Tool — Chameleon Ultra 一体化 MIFARE Classic 工具

基于 Chameleon Ultra 串口协议的 Windows PowerShell 一体化工具：扫卡、全卡 dump、字典攻击、写卡槽模拟、嗅探 + mfkey32 破解，一个脚本全部搞定。

> ⚠️ 仅供学习研究、测试自己拥有的卡片与设备。请遵守当地法律法规，勿用于非法用途。

---

## 功能一览

| 菜单 | 功能 | 说明 |
|------|------|------|
| [1] 扫卡 | 读取 UID / ATQA / SAK / 卡型 | 支持 M1 1K / 4K / Mini 识别 |
| [2] 全卡 dump | 自动试 16 把常见密钥后逐扇区读取 | 破不出的扇区会明确提示，产出 `dump_时间戳.txt` |
| [3] 密钥字典攻击 | 对指定扇区跑 libnfc.db 字典（67 万键） | **断点续跑**，Ctrl+C 中断安全，进度存 `bf_pos_s<扇区>.txt` |
| [4] 写卡槽模拟 | 把 dump 写入变色龙卡槽并切到模拟模式 | dump 不完整时拒绝写入并警告（防覆盖真卡未知数据） |
| [5] 模式切换 | 模拟 / 读卡模式切换 + 激活卡槽 | |
| [6] 嗅探+mfkey32 | 变色龙当模拟卡被真读卡器刷，抓认证数据后自动调 mfkey32v2 破解 | 命中的密钥追加到 `cracked_keys.txt` |

所有产出自动存放在脚本同目录的 `nfc-data\` 文件夹。

## 安装

### 1. 硬件
- Chameleon Ultra 一只（USB 串口，VID_6868 PID_8686，Windows 免驱枚举为 COM 口）
- USB 数据线接电脑

### 2. 软件依赖
- Windows 10/11，PowerShell 5.1（系统自带，无需安装）
- `mfkey32v2.exe`（mfkey32 破解器，功能 [6] 用）— **仓库已附带**
- `libnfc.db` 密钥字典 67 万键（功能 [3] 用）— **仓库已附带**，脚本会自动在脚本同目录找到它

### 3. 运行
1. 下载本仓库全部文件（`Code → Download ZIP` 或 `git clone`，五个文件放同一目录）
2. 右键 `cu-tool.ps1` → **使用 PowerShell 运行**
3. 若被执行策略拦截，用**管理员 PowerShell** 执行一次：
   ```powershell
   Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
   ```

## 使用全流程

### 场景 A：克隆一张卡（饮水机 / 门禁等 M1 卡）

```
插上变色龙 → 运行 cu-tool.ps1
  [1] 扫卡               ← 确认工具能认卡，记下 UID
  [2] 全卡 dump           ← 16 扇区全部 OK 就直接跳 [4]
                          ← 有扇区提示"密钥未找到"就先做 [3]
  [3] 密钥字典攻击         ← 输入扇区号，跑完显示 [HIT] keyA=xxxx
                          ← 每个失败扇区各跑一次
  [2] 再 dump 一次         ← 这次应该 16/16 全 OK
  [4] 写卡槽模拟           ← 回车用最新 dump，输入卡槽号（默认 8）
  [5] 模式切换（可选）      ← 检查/切回模拟或读卡模式
拔下变色龙拿到读卡器上刷 → 完成
```

### 场景 B：门禁只认密钥（卡数据被特殊保护 / 想拿真钥）

```
变色龙保持模拟模式 + 开启嗅探（[6] 自动完成）
把变色龙贴到真门禁读卡器上刷 ≥2 次
回车 → 工具自动读检测日志 + 调 mfkey32v2 破解
显示 [KEY FOUND] → 密钥已存 nfc-data\cracked_keys.txt
之后可用该密钥走 [2] 全卡 dump
```

### 常见问题

| 现象 | 处理 |
|------|------|
| `[X] 未找到变色龙 (VID_6868)` | 检查 USB 线 / 换口重插；设备管理器应有「USB 串行设备 (COMx)」 |
| `[X] 打开 COMx 失败: 拒绝访问` | 关掉其他占串口的程序；仍锁则拔插 CU 重开工具 |
| `[X] 打开 COMx 失败: 端口不存在` | 重插后 COM 号变了，拔插一次让系统重新枚举 |
| dump 有扇区失败 | 属正常 — 该扇区密钥不在常见钥里，走 [3] 字典攻击 |
| [4] 提示 dump 不完整 | 用 [3] 补破缺的扇区再 dump；强行 y 会用 0x00/默认钥覆盖未知数据 |
| 字典攻击很慢 | 67 万键最坏 ~12 小时（15 键/秒），中断安全可分多次跑 |

## 技术细节（协议层）

变色龙 Ultra 官方固件串口协议（115200 8N1，**必须 DTR/RTS 拉高**，否则设备假死）：

- 帧格式：`11 EF | cmd(2) | status(2) | len(2) | LRC2 | data(len) | LRC3`
  - LRC2 = header[2..7] 求和取补；LRC3 = data 求和取补
- 本工具用到的命令（十进制 ID）：
  - `1001/1002` 模式设置/读取、`1003` 选卡槽、`1004` 卡槽卡型、`1005` 恢复默认数据、`1006` HF 使能、`1009` 存 flash
  - `2000` HF14A 扫卡、`2007` 单钥认证、`2008` 认证+读块
  - `4000` 写模拟块（≤31 块/帧）、`4001` 反碰撞（ATQA 在线序 `04 00`）
  - `4004/4005/4006` 嗅探使能 / 日志数 / 日志读取
- 状态码：`0x0000` 成功、`0x0006` 认证失败、`0x0066` 非读卡模式、`0x0067` 未知命令、`0x0068` HF_TAG_OK（写模拟块的正常返回）

实测性能：密钥认证 ~15 键/秒；全卡 dump ~6 秒；写卡槽 ~2 秒。

## 目录结构

```
cu-tool.ps1           主脚本（唯一必需）
mfkey32v2.exe         mfkey32 破解器（功能[6]用，仓库附带）
libnfc.db             密钥字典 67万键（功能[3]用，仓库附带）
nfc-data/             运行产出（自动创建）
  ├─ dump_时间戳.txt     全卡 dump
  ├─ bf_pos_s<N>.txt     字典攻击断点
  ├─ bf_log_s<N>.txt     字典攻击命中记录
  ├─ sniff_时间戳.txt     嗅探日志
  └─ cracked_keys.txt    破解出的密钥
```
